# Meet Bukayo Saka | Arsenal

A static HTML/CSS landing page for a fictional fan event featuring Arsenal footballer Bukayo Saka.

## Project Overview

This project is a single-page promotional website designed to advertise an event where fans can meet Bukayo Saka at Emirates Stadium. The page includes:

- A sticky navigation bar
- A hero section with a strong call-to-action
- An “About” section describing the event and player
- Event details such as date, time, and venue
- A schedule of day activities
- Ticket options with pricing and benefits
- A footer with event contact information

This project is built using plain HTML and CSS only, with no frameworks or JavaScript required.

## Files Included

- [index.html](index.html) – main page structure and event content
- [style.css](style.css) – styling and layout for the page
- [image folder/saka picture.png](image%20folder/saka%20picture.png) – image used for the hero banner and profile section

## Design Details

The page uses a sports-themed visual style inspired by Arsenal branding:

- Red, white, and black color palette
- Bold headings and strong contrast
- Rounded ticket cards with subtle shadows
- Sticky top navigation
- Large hero banner image with central text
- Distinct sections for event information and ticket packages

## Website Sections

### Navigation
The navigation menu links to:
- About
- Event
- Schedule
- Tickets

### Hero Section
The hero section introduces the event with:
- Main heading: “Meet Bukayo Saka”
- Date and venue
- A “Book Now” call-to-action button

### About Section
This section explains who Bukayo Saka is and what fans can expect from the event, including:
- Autographs
- Photos
- Q&A opportunities

### Event Details
The event page displays:
- Date: Saturday 12 December 2026
- Time: 10:00am – 1:00pm
- Venue: Emirates Stadium, London

### Event Schedule
A timeline-style schedule lists the event flow:
- Doors open
- Welcome introduction
- Meet and greet
- Q&A
- Autograph signing
- Photo opportunities
- Refreshments
- Closing speech

### Tickets
Three ticket options are presented:
- Standard Ticket – £50
- Gold Ticket – £100
- VIP (coming soon)
